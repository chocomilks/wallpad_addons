# Changelog

## 0.1.6
- 현관문 열림센서 연동(설정 탭에서 지정)
  - 실제 스캔 시작 전: 문이 열려 있거나 문 사용 후 금지 시간(기본 180초) 안이면 건너뜀 — 나가는 가족을 인식해 잠긴 문을 다시 여는 것 방지.
    센서 상태를 알 수 없을 때(unavailable)는 설정으로 선택: 건너뜀(기본) / 얼굴+폰 정책인 사람만 열 수 있게 하고 스캔
  - 스캔 중 문이 열리면 즉시 중지 (0.5초 간격 확인)
  - 판정 순간 문이 이미 열려 있으면 열기 신호를 보내지 않음
  - 자동화·MQTT·패널 어느 경로로 시작해도 같은 검사 적용 (테스트 스캔은 제외)

## 0.1.5
- 여러 명이 동시에 잡힐 때: 프레임의 얼굴을 최대 4개까지 모두 판정하고, 등록된 사람마다 연속 일치 횟수를 따로 셈
  (가장 큰 얼굴만 보던 방식은 두 사람이 번갈아 크게 잡히면 연속 횟수가 계속 초기화됨)
- 얼굴이 가려지는 등 한 프레임 놓치는 건 허용, 2프레임 연속 불일치면 그 사람 횟수 초기화
- 테스트 화면: 썸네일에 얼굴 상자·번호(초록 통과/빨강 불일치/회색 품질 미달), 얼굴별 점수, 사람별 연속 횟수

## 0.1.4
- 문 열기 스크립트가 HA에 없으면 '열림'으로 잘못 기록하던 문제: 호출 전 존재 확인, 실패 사유를 결과·기록에 표시

## 0.1.3

- cmxmm이 JPEG를 다 쓰기 전에 읽던 문제: 파일 크기가 멈출 때까지 대기, 끝 표식(FFD9) 없으면 잘린 프레임으로 처리
- 캡처 요청 응답 대기 5초 → 3초
- 속도: 검출 입력 320(설정 가능), 추론 스레드 = CPU 수, 시작 시 예열·속도 측정(상단 칩 표시)
- 테스트 화면: 프레임별 캡처/처리 시간, 캡처 통계(정상·실패·잘림·첫 프레임 시각), 같은 프레임 중복 표시 수정
