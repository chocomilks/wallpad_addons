# Changelog

## 0.1.3
- 첫 프레임이 늦게 오면 판정 창이 끝나버리던 문제: 판정 창을 첫 정상 프레임 도착부터 계산
- cmxmm이 JPEG를 다 쓰기 전에 읽던 문제: 파일 크기가 멈출 때까지 대기, 끝 표식(FFD9) 없으면 잘린 프레임으로 처리
- 캡처 요청 응답 대기 5초 → 3초
- 속도: 검출 입력 320(설정 가능), 추론 스레드 = CPU 수, 시작 시 예열·속도 측정(상단 칩 표시)
- 테스트 화면: 프레임별 캡처/처리 시간, 캡처 통계(정상·실패·잘림·첫 프레임 시각), 같은 프레임 중복 표시 수정

## 0.1.2
